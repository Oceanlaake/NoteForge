# Lecture 2: Defining and using Classes

## 编译
- 标准编译方法是将.java文件编译成（使用javac-编译器）.class文件，然后使用（java-解释器）运行。
- 但这不是唯一的方法
- class文件
    - 已经过类型检查
    - 机器更容易执行
    - 保护源代码

## class
- 每一种方法都必须和类联系起来
- 类里面只有包含main才能被直接运行
- 然而我们可以在其他类中调用这个类中定义的方法（狗和狗发射器）
- 类中可以包含数据
### 静态变量与静态方法
- 静态变量：在类中被定义，可以直接使用类名调用，也被所有实例成员共享，不能被修改
- 静态方法：使用类名调用，他不能使用this关键字来访问一些实例中才有的数据
- 如Math.round()
### 实例变量与实例方法
- Instance varible：在类中定义的变量，但在实例化中可以被赋值（否则使用默认值）
- Constructor：构造函数，实例化过程中被调用，并初始化该实例的一些实例变量
- Non-static method（instance method）：由实例调用，可以使用this关键字来访问实例变量
- 对象数组：分为初定义和单独定义其中每一个实例
- 静态变量虽然也可以被实例变量调用（共享），但是最好还是使用类名去调用

- public static void main(String[] args)
- 接受命令行参数，从类名之后从0开始编号
